## Design suggestions

1. **Allow clearing measured values with Empty + Enter in `[data-dim-editor]`**: When the user submits an empty string in `DimEditor.tsx`, clear the face/wall measured value instead of treating it as a no-op cancel.
2. **Record inline `[data-dim-editor]` edits on the undo stack**: Commit measured-length changes from the plan editor as a single undoable action so `Ctrl/Cmd+Z` / `Undo` reverts them as specified.
3. **Avoid `WC-2`/`WC-4` and outside-dim badge collisions when `Wall labels` is `On`**: Shift `[data-wall-number]` badges slightly further into the wall band or suppress overlapping badges on short walls (`86`, `40`, `66`).
4. **Compact the bottom hint bar on narrow viewports (`390x844`)**: Collapse or shorten the 4-line hint text on mobile so it does not cover the lower part of the floorplan.
5. **Offset tape-measure label (`traced 200,5`) away from room tags**: Place tape-measure labels slightly above the line or nudge when intersecting `[data-room-label]`.
6. **Add `id` / `name` attributes to form inputs**: Resolves the 16 DevTools form-field accessibility issues.
