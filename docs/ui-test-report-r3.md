## Design suggestions

1. **Reset `CommandPalette` active selection to index `0` on query change and keep it bounded**: When filtering to `"bearing"` + `ArrowDown` or `"Units: m"`, no `<option>` remained `selected`, so `Enter` did not execute until clicked.
2. **Include the enclosing room in `Tab` cycle on wall centerline**: Clicking/hovering `(1017, 862)` on `Door on wall SE-3` cycled `Door -> Wall W9 (Side A) -> Wall W9 -> Door` without `Séjour (SE)` or `Entrée (EN)`. Including the adjacent room(s) in `pickStack` for wall/door hits would match the expected 4-step cycle.
3. **Give the expanded mobile `ToolHints` button full available width**: At `390x844`, the expanded hint button stayed `106.4 px` wide and wrapped to `472 px` tall; allowing `max-w-[calc(100vw-2rem)]` when expanded will keep it compact.
4. **Add `id` / `name` attributes to form inputs**: Clears the remaining browser form-field accessibility issues.
